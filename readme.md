# Power BI Data Repository

Welcome to my GitHub repository where I store various `.csv` datasets used in Power BI development projects.

## Purpose

This repository serves as a central location to host CSV files that are consumed in Power BI dashboards and reports. These files may include raw data, processed datasets, or intermediate data used during analytics workflows.

## How It Works

- 📁 **Data Source**: The CSV files stored here are either:
  - Processed and exported using **Python scripts**, or
  - Manually uploaded via the **GitHub web interface**.

- 🔄 **Updates**: I regularly commit updates to the datasets as I clean, transform, or extend them using Python, ensuring the most up-to-date versions are always available for my Power BI projects.

## Usage

You can clone or download this repository if you'd like to use the datasets in your own analytics or visualization projects. Feel free to reference the files directly in Power BI via a web connector, raw GitHub links, or local copies after cloning.
